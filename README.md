# BACKROOMS FPS — Професійна дошка монтажу та таймлайн відео

Інтерактивна монтажна дошка розслідування та таймлайн сценарію для монтажу відео про **Backrooms FPS**.

Сайт: **https://shkibidishprot.github.io/siteforvideo/**

---

## 🎬 Структура таймлайну (58 карток · 6 глав + Пролог)

- **Пролог — МАТЧ БЕЗ ТЕБЕ** (Картка: 01)
- **1. БУДЬ ЛАСКА, ГРАЙТЕ ПРАВИЛЬНО** (Картки: 02–09)
- **2. ВИХОДИМО З ГРИ** (Картки: 10–17)
- **3. УСЕ ПІД КОНТРОЛЕМ** (Картки: 18–31)
- **4. ТЕПЕР ЗАЛИШИЛОСЯ ПЕРЕМОГТИ** (Картки: 32–42)
- **5. БУДЬ ЛАСКА, НЕ ПАНІКУЙТЕ** (Картки: 43–53)
- **6. ТЕПЕР МОЖНА БЕЗ ПЛАНУ** (Картки: 54–58)

---

## 📋 Структура кожної картки

1. **№ картки у відео** (`#01` ... `#58`)
2. **Рівень айсберга** (бейдж глибини)
3. **Назва для фото / Головний заголовок** (найбільший контрастний заголовок для кадру)
4. **Точний текст для начитки** (окремий блок дикторського тексту з кнопкою швидкого копіювання)
5. **Звичайна / робоча назва**
6. **Запасна назва з попереднього плану**

---

## 🕹️ Керування та гарячі клавіші

- `←` / `→` : Попередня / наступна картка
- `↑` / `↓` : Попередня / наступна глава
- `Пробіл` : Запуск / пауза автопоказу таймлайну
- `O` : Перемикання огляду всієї дошки
- `Z` : Фокус на активній главі
- `T` : Відкрити табличний план / сценарій (з експортом у Markdown)
- `C` : Режим кіно (приховати інтерфейс)
- `/` : Швидкий пошук за картками
- `Esc` : Закрити модальні вікна / вийти з кіно
